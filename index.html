透视投影深度精度对比

同一场景：近处薄片 + 远处墙面 + 墙面接触贴片。切换深度方案，观察条纹阴影与接触闪烁。

当前环境不支持 WebGL2，请使用新版 Chrome / Edge / Firefox 打开。

实验说明

  • 远处墙面位于远平面 90% 处，墙前一片仅相距“接触缝隙”的贴片，二者投影在同一像素上竞争深度。
  • 近处薄片位于近平面约 5 倍距离处，用来检验近处物体是否仍被正常绘制。
  • “Z-fighting 像素”统计两表面量化后深度完全相同的像素；“闪烁像素”统计相机微抖动前后归属发生切换的像素。
  • 深度分层条纹把连续深度按量化桶着色，桶越粗条纹越宽，直观显示远端精度损失。
