# TAA Demo — 带历史颜色缓冲的时域抗锯齿

纯 numpy 实现的软件渲染 + TAA 后处理管线，用于演示和验证时域抗锯齿的核心机制。

## 运行

```bash
python3 -m taa_demo.main
```

输出写入 `artifacts/taa/`：每个关键帧生成三/四视图对比图（`*_views.png`）、
栏杆区域局部放大图（`*_zoom.png`）、静态场景收敛曲线
（`railings_static_convergence.png`）和逐帧指标（`metrics.txt`）。

## 算法（taa_demo/taa.py）

`TAA` 类保存上一帧的颜色、深度和相机矩阵（V 与未抖动的 P）。每帧：

1. **重投影**：用当前深度 + 未抖动 VP 的逆变换把像素反投影到世界空间，
   再用上一帧 VP 投影回历史帧像素坐标（Halton(2,3) 亚像素抖动在此过程中去除）。
2. **有效性判断**：重投影坐标在画面内，且与历史深度（最近邻采样）的相对误差
   不超过 `depth_tol`（默认 5%）才接受历史——遮挡关系变化（disocclusion）在此被拒绝。
3. **邻域钳制**：历史颜色被钳制到当前帧 3x3 邻域的 min/max 包围盒内，
   进一步压制镜头运动导致的残留鬼影。
4. **混合**：命中历史时 `out = 0.1 * current + 0.9 * history_clamped`（静态持续收敛）；
   被拒绝的像素回退为 `alpha = 1.0`（完全使用当前帧，无拖影）。

`naive=True` 模式关闭全部拒绝与钳制逻辑，作为鬼影对照组。

## 场景（taa_demo/main.py）

| 场景 | 内容 | 验证点 |
|---|---|---|
| `railings_static` | 细栏杆 + 棋盘墙，静态相机 24 帧 | 有效率高（~97%），MSE 对 4x 超采样参考持续收敛 |
| `fast_pan` | 相机 20 帧内横摇 60°（~12px/帧） | 拒绝率上升（~9-12%），naive 对照组拖出整片鬼影而 TAA 保持清晰 |
| `dynamic_object` | 红色立方体横穿画面，相机缓慢转动 | 运动物体边缘深度校验拒绝历史（~6-10%），无红色拖尾 |

## 指标

`metrics.txt` 逐帧记录：

- `valid_ratio`：重投影命中（画面内 + 深度一致）的像素比例
- `rejected_ratio`：被拒绝回退到当前帧的像素比例（= 1 - valid）
- `mse_raw` / `mse_taa` / `mse_naive`：与参考图像的均方误差
  （静态场景参考为 4x 超采样；横移场景参考为当前帧无抖动渲染）

## 渲染器（taa_demo/renderer.py）

numpy 软件光栅化器：透视校正插值、深度缓冲、近平面三角形裁剪、
程序棋盘纹理、Lambert 光照，输出颜色 + 线性视空间深度。
